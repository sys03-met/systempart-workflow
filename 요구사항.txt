3. 기능 요구사항 명세 (Functional Requirements)

FR-01. 작업 등록 및 수정 관리

작업 등록:

작업지시일, 요청자, 작업 파트(복수 선택 가능), 작업내용, 세부내용, 완료예정일, 진행률 입력 후 등록

등록 즉시 '진행 중 작업 목록'에 반영

작업 수정 (진행사항 업데이트):

세부내용에 날짜별 히스토리 추가 작성 지원 (예: 줄바꿈 기반 메모 관리)

진행률(0~100%) 슬라이더 또는 숫자 입력을 통한 업데이트

진행률을 100%로 변경 저장 시, 해당 작업은 즉시 '진행 중' 목록에서 제외되고 '완료 작업' 목록으로 자동 이관



FR-02. 작업 목록 조회 및 필터링

진행 작업 조회 (기본 화면):

진행률 0% ~ 99%인 작업만 기본 출력

최신 작업지시일 또는 순번 기준 정렬 (기본 내림차순)

파트별 필터링 / 전체 조회:

탭 또는 드롭다운/체크박스를 통해 전체 / 검침 / WEB / NMS / 연구과제별 필터링 지원

복수 파트에 속한 작업은 해당 파트 선택 시 모두 노출

완료 작업 조회 (완료 전용 페이지):

진행률 100%인 작업만 별도 분리하여 조회하는 전용 메뉴/페이지 제공

완료된 작업의 이력 열람 및 필요 시 진행률 재수정을 통한 진행 중 복원 기능 지원

검색 기능:

작업내용, 세부내용, 요청자 키워드 검색 지원

FR-03. 데이터 추출 (Excel Export)

진행 중 작업 엑셀 다운로드:

현재 필터링된 조건(파트별, 검색어 등) 또는 전체 '진행 중 작업(진행률 < 100%)' 목록을 .xlsx 형식으로 다운로드

다운로드 파일 양식은 기존 진행업무 정리.xlsx의 컬럼 구조(순번, 지시일, 요청자, 예정일, 진행률, 파트별 표기, 작업내용, 세부내용)를 유지하여 생성
