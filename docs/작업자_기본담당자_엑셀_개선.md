# 작업자·기본 담당자·엑셀 개선

작업일: 2026-09-21

## 반영 내용

- 엑셀 다운로드의 헤더와 데이터 행에 세로 중앙 정렬과 줄바꿈을 적용했습니다.
- 진행률이 100%가 되면 중요 표시를 제거하도록 완료 버튼, 직접 저장, CSV 가져오기, 기존 데이터 정규화 경로를 보완했습니다.
- 작업자 필드를 작업 등록/수정, 목록 표·모바일 카드, 정렬·검색, CSV 양식·가져오기, 엑셀 다운로드에 추가했습니다.
- 동봉된 `templates/작업등록_양식.csv`에도 작업자 열을 반영했습니다.
- 설정에서 파트별 기본 작업자를 입력하면 로컬 저장소 또는 Firebase 설정에 저장됩니다.
- 새 작업에서 파트를 선택하면 선택된 파트 중 첫 번째로 지정된 기본 작업자가 자동 입력됩니다. 직접 수정한 작업자는 파트 변경 시 덮어쓰지 않습니다.
- 기존 진행 중 작업도 작업자가 비어 있으면 작업 목록/설정 로드 시 기본 작업자가 자동 적용됩니다.
- 파트 이름 변경 시 기본 작업자 설정을 함께 이동하고, 파트 삭제 시 해당 설정을 함께 제거합니다.
